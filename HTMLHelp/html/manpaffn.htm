Affine Transformations

Affine transformations are ManpWIN's most flexible fractal transformations, providing precise control over scaling, stretching, shearing, reflection, rotation and translation.

Overview

Affine transformations provide precise geometric control over the coordinates used to calculate a fractal. They can be used for scaling, stretching, compression, shearing, reflection, rotation, translation, and combinations of these operations.

Press Ctrl+X to open the Fractal Transformations dialog, select Affine, then press Parameters....

Affine transformations use six values: a, b, c, d, e and f. The parameter dialog arranges them in the same form as the transformation: 

a    b    e
c    d    f

The corresponding equations are: 

x' = a*x + b*y + e
y' = c*x + d*y + f

This layout makes it possible to see how the six parameters affect the coordinates without treating them as six unrelated numbers.

The Identity Transformation

The default Affine transformation is: 

1    0    0
0    1    0

This leaves the coordinates unchanged: 

x' = x
y' = y

When experimenting with Affine transformations, this is a useful starting point. Change one or two values at a time and observe the result.

What the Parameters Do

Parameter Main Effect
a Horizontal scaling contribution from x
b Horizontal shear contribution from y
c Vertical shear contribution from x
d Vertical scaling contribution from y
e Horizontal translation of the transformed coordinate
f Vertical translation of the transformed coordinate

The parameters may also be combined. For example, the same transformation can simultaneously scale, shear, rotate and translate the coordinates.

Horizontal Scaling

To change the horizontal coordinate scale, change a while leaving the other principal values unchanged.

Scale x by 2

2    0    0
0    1    0

This produces: 

x' = 2*x
y' = y

The transformed x coordinate is therefore twice its original value.

Scale x by 0.5

0.5    0    0
0      1    0

The transformed x coordinate is reduced to half its original value.

Vertical Scaling

Vertical scaling is controlled primarily by d.

Scale y by 2

1    0    0
0    2    0

Scale y by 0.5

1    0      0
0    0.5    0

Horizontal and vertical scaling may be different. This allows the coordinate system to be stretched or compressed independently in either direction.

Uniform Scaling

To scale both coordinates by the same amount, give a and d the same value.

Scale both coordinates by 1.5

1.5    0      0
0      1.5    0

Both x and y are multiplied by 1.5.

Horizontal Shear

A horizontal shear is produced by changing b: 

x' = x + b*y
y' = y

The approximate shear angle is: 

angle = atan(b)

Some useful values are:

Shear Angle b
15° 0.268
30° 0.577
45° 1.000

Approximately 30° horizontal shear

1    0.577    0
0    1        0

This means that the x coordinate is progressively displaced according to the value of y.

Vertical Shear

A vertical shear is produced by changing c: 

x' = x
y' = c*x + y

The same angle relationship applies: 

angle = atan(c)

Approximately 30° vertical shear

1        0    0
0.577    1    0

The y coordinate is progressively displaced according to the value of x.

Rotation

Affine transformation can also rotate coordinates. For a rotation by an angle θ around the origin: 

a =  cos(theta)
b = -sin(theta)
c =  sin(theta)
d =  cos(theta)

30° Rotation

 0.866025    -0.500000    0
 0.500000     0.866025    0

45° Rotation

 0.707107    -0.707107    0
 0.707107     0.707107    0

90° Rotation

0    -1    0
1     0    0

These examples rotate about the coordinate origin (0,0).

For ordinary view rotation around the centre of the current image, use the rotation controls in the main Fractal Transformations dialog rather than constructing an Affine rotation manually.

Rotation Around Another Point

Affine rotation may also be performed around a selected point (cx, cy). First calculate the rotation coefficients: 

a =  cos(theta)
b = -sin(theta)
c =  sin(theta)
d =  cos(theta)

Then calculate: 

e = cx - a*cx - b*cy
f = cy - c*cx - d*cy

The point (cx, cy) then remains fixed while the surrounding coordinates rotate around it.

Reflection

Negative scaling values can be used to reflect coordinates.

Reflect x

-1    0    0
 0    1    0

This changes x to -x while leaving y unchanged.

Reflect y

1     0    0
0    -1    0

This changes y to -y while leaving x unchanged.

Reflect both coordinates

-1     0    0
 0    -1    0

This is equivalent to a 180° rotation about the origin.

Translation

The e and f parameters add fixed amounts to the transformed coordinates.

Add 0.5 to x

1    0    0.5
0    1    0

Add 0.25 to y

1    0    0
0    1    0.25

Add 0.5 to x and 0.25 to y

1    0    0.5
0    1    0.25

These values alter the coordinates supplied to the fractal calculation. The apparent movement of the rendered fractal may therefore be opposite to the direction suggested by the sign of the translation.

Combining Transformations

The real power of Affine transformation comes from combining several effects in the same six parameters.

For example: 

1.5    0.577    0
0      1        0

combines a 1.5 times horizontal coordinate scale with an approximately 30° horizontal shear.

Similarly: 

0.707107    -0.707107    0.5
0.707107     0.707107    0.25

combines a 45° rotation about the origin with translation of the transformed coordinates.

Invertibility

An Affine transformation can be reversed provided that: 

a*d - b*c != 0

The quantity a*d - b*c is the determinant of the transformation. If it is zero, the transformation collapses the two-dimensional coordinate plane onto a line or point and cannot be uniquely reversed.

For normal exploration, avoid parameter combinations that produce a zero determinant.

Practical Tips

  • Begin with the identity values: 1 0 0 / 0 1 0.
  • Change one value at a time while learning what the parameters do.
  • Use small shear values initially; even values below 1 can produce strong effects.
  • Remember that 0.577 corresponds to approximately 30° shear.
  • Use equal values for a and d when uniform coordinate scaling is required.
  • Use the main rotation controls when ordinary view rotation is all that is needed.
  • More complex effects can be built by combining scaling, shear, rotation and translation.

More About Colour

Overview

ManpWIN supports several colour systems which combine the classic FRACTINT palette approach with modern True Colour palette generation. These colour systems are independent of the fractal calculation itself, allowing the same fractal to be rendered using different palette sources.

Internally, ManpWIN supports four primary colour states:

  • Default FRACTINT Palette
  • Default True Colour Palette
  • Palette Table Mode
  • Custom True Colour Palette

Default FRACTINT Palette

This is the classic FRACTINT-compatible palette supplied with ManpWIN.

It provides compatibility with traditional FRACTINT rendering styles and many historic fractal images.

This palette is selected when: 

UseFractintPalette=TRUE

is specified in MANPWIN.INI.

Default True Colour Palette

This palette is generated from ManpWIN's built-in True Colour parameters.

It is selected when: 

UseFractintPalette=FALSE

is specified in MANPWIN.INI.

The palette is generated from a set of colour parameters and does not require an external palette file.

Palette Table Mode

Palette Table mode uses an explicit RGB palette table.

Typical sources include:

  • MAP files
  • PAR embedded palettes
  • PNG embedded palettes
  • KFR embedded palettes
  • Palette Editor output

Once loaded, all of these palette sources are treated identically by the renderer. The original source is no longer important.

Custom True Colour Palette

Custom True Colour palettes are generated from user-defined colour parameters.

Typical sources include:

  • COL files
  • Random palette generation

These palettes are generated from six True Colour parameters and may be saved back to COL files.

Switching Between Colour Systems

Press Ctrl+P to switch between the default FRACTINT palette and the default True Colour palette.

Loading a MAP, PAR, PNG or KFR palette automatically activates Palette Table mode.

Loading a COL file or generating a random palette automatically activates Custom True Colour mode.

Saving Colour Information

COL files store the six True Colour generation parameters used to create a generated palette.

MAP files store explicit RGB palette entries.

Because a palette table does not contain the original True Colour parameters, a MAP palette cannot automatically be converted into a COL file.

Similarly, once a palette has been loaded from a MAP, PAR, PNG or KFR file, the original True Colour parameters are no longer meaningful.

Tierazon Colouring

Tierazon colouring and filtering use a different colour model from the standard ManpWIN colour systems.

To exit Tierazon colouring:

  • Load a palette map using Q
  • Load a True Colour palette using L
  • Or reselect the fractal using T

Notes

For advanced palette editing, see Palette Editing.

Different fractals and colouring methods may respond differently to colour selection. Experimentation with both palette systems is encouraged.

The separation of palette generation, palette storage and fractal rendering allows ManpWIN to support classic FRACTINT workflows, modern True Colour rendering, animation systems, external file formats and future colour extensions while maintaining rendering consistency.

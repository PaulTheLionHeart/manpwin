Inverse Julia Fractals

Overview

Inverse Julia fractals generate points on a Julia set by repeatedly applying inverse forms of the Julia iteration rather than calculating whether each screen pixel escapes.

ManpWIN provides an extended Inverse Julia implementation supporting powers from 2 through 20, several point-generation methods, animation, and Real-Time Inverse Julia exploration.

How Inverse Julia Works

For the ordinary quadratic Julia set: 

z(n+1) = z(n)^2 + C

the inverse operation is: 

z(n) = +/- sqrt(z(n+1) - C)

Each point can therefore have more than one inverse value. Repeatedly choosing between these inverse values generates points belonging to the Julia set.

For higher powers, ManpWIN calculates the corresponding inverse roots. A power of N produces N possible inverse roots at each step.

Supported Powers

ManpWIN supports Inverse Julia fractals for powers from 2 through 20.

The normal quadratic case uses power 2. Higher powers produce additional branches and increasingly complex rotational structures.

Inverse Julia may be generated only from the Mandelbrot or Power fractals. The selected source fractal determines the power used.

This is more restricted than ordinary Julia mode, which is available for many pixel-based fractal types.

Generation Methods

Breadth First

Breadth First processing expands the inverse tree level by level. Points nearer the beginning of the tree are processed before deeper branches.

Depth First

Depth First processing follows one branch of the inverse tree before returning to explore alternative branches.

The Left / Right option controls which branch is followed first where this choice is applicable.

Random Walk

Random Walk selects inverse branches randomly and follows a continuously evolving path through the Julia set.

Random Run

Random Run is similar to Random Walk, but continues along a selected branch for a configurable interval before choosing another branch.

Parameters

The Inverse Julia parameters include:

  • Real C – real part of the Julia constant
  • Imaginary C – imaginary part of the Julia constant
  • Maximum Hits – controls the number of times a screen point may be plotted
  • Method – Breadth First, Depth First, Random Walk, or Random Run
  • Left / Right – branch preference used by applicable methods
  • Random Run Interval – controls the run length used by Random Run
  • Power – order of the inverse Julia calculation

Real-Time Inverse Julia

Press 0 to toggle Real-Time Inverse Julia on or off.

Real-Time Inverse Julia allows the Julia constant to be changed interactively while viewing the corresponding Inverse Julia image.

The mouse position in the source Mandelbrot or Power fractal determines the Julia constant. This provides a rapid way to explore how the Inverse Julia structure changes throughout the source fractal.

Real-Time Inverse Julia also works with rotated Mandelbrot views. The mouse position is transformed back into the corresponding fractal coordinate before the Inverse Julia image is calculated.

Inverse Julia Animation

Inverse Julia animation varies the Julia parameter over a sequence of frames, allowing the changing branch and spiral structures to be viewed as an animation.

Use Shift+J to set up an Inverse Julia animation.

The power is inherited from the source Mandelbrot or Power fractal and is preserved throughout the animation.

When the animation is complete, ManpWIN restores the original source fractal.

Zooming

Inverse Julia images may be zoomed in the normal way. However, because the image is generated from sampled inverse-orbit points, zooming an existing Inverse Julia image may not always preserve the same level of fine detail as generating the Inverse Julia set directly at the new location.

For the best detail, regenerate the Inverse Julia image after selecting the desired region.

Fractint Compatibility

ManpWIN supports the Fractint julia_inverse concept and can interpret the corresponding miim= parameter from Fractint parameter files.

The ManpWIN implementation extends the original approach with higher powers, additional generation methods, animation, and Real-Time Inverse Julia.

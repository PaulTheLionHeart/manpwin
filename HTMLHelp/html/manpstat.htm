Status Information

Press TAB while rendering or after a render completes to display the Status Information window.

The Status Information window provides detailed information about the current fractal, including location, image size, precision, parameters, bailout values, rendering mode, thread count, and other diagnostic information relevant to the selected fractal type.

The information displayed varies depending on the fractal engine being used. For example, perturbation and slope-rendered fractals may display progress information and engine-specific parameters.

The contents of the Status Information window can be copied directly to the clipboard using the Copy button.

Use the vertical scroll bar to view additional information when the report extends beyond the visible window.

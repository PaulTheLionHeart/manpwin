Revision History

ManpWIN has undergone continuous development over many years, with ongoing improvements to performance, precision, and fractal exploration capabilities.

Latest Release (September 2026)

ManpWIN 4.05

ManpWIN 4.05 is a major perturbation, slope rendering, and parameter architecture update focused on improving rendering consistency, fractal interoperability, and long-term maintainability.

Recent Improvements

  • Unified ordinary filtering behaviour across pixel, perturbation, and derivative slope rendering.
  • Added filter and biomorph support to derivative slope rendering while retaining slope lighting.
  • Fixed several forward-difference slope rendering issues, including subtype 13 calculations, special-colour indexing, and pixel-state handling.
  • Corrected palette start, offset, and shift handling, and added configurable pre-palette colouring for iterations below the selected Start Palette value.
  • Expanded and reorganised perturbation and slope parameter handling, including updated dialogue boxes, parameter animation, and parameter-file save/load support.
  • Improved conversion between equivalent pixel and perturbation fractals, including Polynomial fractals.
  • Extended Perturbation Polynomial support to eighth-order polynomials.
  • Fixed a long-standing perturbation power distortion caused by reference orbits being generated before the correct fractal degree was established.
  • General rendering, stability, and internal architecture improvements.

Previous Releases

ManpWIN 4.04

ManpWIN 4.04 is a stability and internal architecture update focused on multi-threaded rendering reliability, pixel rendering lifecycle management, perturbation filtering, and general rendering consistency.

  • Fixed double-double and quad-double trigonometric function issues that affected some Tierazon fractals.
  • Fixed 3D rendering in both perturbation and pixel modes by correcting the effective thread count used during rendering.
  • Improved multi-threaded pixel rendering startup and shutdown reliability.
  • Fixed unsafe partial thread startup handling when worker creation or memory allocation fails.
  • Removed obsolete thread-completion flags and now use worker thread handles directly for reliable completion detection.
  • Applied the same thread-completion simplification to perturbation and slope rendering.
  • Fixed a long-standing issue where changing the configured thread count during an active render could be overwritten when the previous render finished.
  • Improved worker strip ownership and symmetry handling during multi-threaded pixel rendering.
  • Fixed Tierazon filter initialisation ordering that could cause visible seams between multi-threaded rendering strips.
  • Corrected Tierazon filtering in perturbation rendering so filter processing begins at the correct orbit iteration.
  • Improved perturbation Tierazon filter coordinate initialisation.
  • Audited and simplified CPixel initialisation, arithmetic setup, worklist handling, symmetry processing, and thread lifecycle management.
  • General internal cleanup and stability improvements.

ManpWIN 4.03e

ManpWIN 4.03e is a maintenance and stability update focused on improving perturbation rendering, deep-zoom reliability, Kalles Fraktaler compatibility, and fractal metadata handling.

  • Improved perturbation reference generation and rebasing during extremely deep zooms.
  • Fixed a perturbation rebasing issue affecting deep zooms when BLA was disabled.
  • Improved reference orbit stability near the Mandelbrot set boundary around -2.0.
  • Reduced perturbation artefacts encountered during very deep zoom rendering.
  • Fixed reading and writing of smoothing values in Kalles Fraktaler (.KFR) files.
  • Improved metadata rebuilding for derivative-based, Tierazon, and Mandelbrot derivative fractals, ensuring parameter dialogue boxes always reflect the current fractal settings.
  • General stability improvements and internal code maintenance.

ManpWIN 4.03d

ManpWIN 4.03d is a maintenance and stability update focused on improving animation reliability during extremely deep zoom sequences together with more robust handling of very large palettes.

  • Improved animation script processing for animations using very large iteration counts.
  • Improved palette handling when reading and writing animation script files.
  • Prevented palette processing from exceeding internal palette limits during animation generation.
  • Improved robustness when loading animation scripts containing large palette definitions.
  • Improved zoom overlay calculations for extreme magnifications.
  • Added documentation describing the logarithmic zoom calculation used for the zoom overlay.
  • General stability improvements and internal code maintenance.

ManpWIN 4.03c

ManpWIN 4.03c is a build and deployment modernisation release focused on simplifying installation, improving maintainability, and adopting a modern CMake/vcpkg build environment.

  • Migrated third-party libraries to modern CMake and vcpkg manifest mode.
  • Updated the build system to use static runtime libraries and static third-party library linking.
  • Simplified deployment by producing a self-contained executable with no third-party runtime DLLs required.
  • Updated installer and build scripts to support the new CMake build structure.
  • Updated the project to build cleanly against current releases of libpng, zlib, GMP and MPFR.
  • Removed legacy dependencies on internal libpng implementation details.
  • General build system cleanup and maintenance.
  • Numerous internal improvements and stability updates.

  • Added a dedicated Help page for the Status Information window.

  • Added rendering mode reporting to the Status Information window.
  • Added thread count reporting to the Status Information window.
  • Improved perturbation reference-build progress reporting.
  • Improved perturbation rendering progress reporting.
  • Improved multi-threaded pass reporting for raster fractals.
  • Removed misleading pixel position reporting from status displays.
  • Added clipboard copy support to the Status Information window.
  • Updated keyboard command documentation and help links.
  • Numerous internal cleanups and bug fixes.

ManpWIN 4.03a

ManpWIN 4.03a is a major stability and infrastructure update focused on perturbation rendering, animation export reliability, palette handling, and modernisation of the internal file and metadata systems.

  • Extended perturbation support for additional transcendental and fractional-power functions including:
    • Exp
    • Sin
    • Cos
    • Sinh
    • z^(n + 0.5)
  • Extended perturbation derivative slope rendering support to the new transcendental and fractional-power function families.
  • Fixed distortion bug affecting perturbation cubic rendering.
  • Complete rewrite and stabilisation of file read/write systems.
  • Overhauled management and separation of fractal metadata and rendering data.
  • Fixed crash when reading Fractint PAR files.
  • Fixed clipboard handling issues that could:
    • prevent clipboard loading
    • interfere with normal program shutdown
  • Fixed intermittent horizontal and vertical line artifacts appearing in derivative slope rendering.
  • Fixed status message handling when opening PNG files.
  • Fixed filename offset issues in file dialogue boxes when handling long filenames.
  • Fixed Slope dialogue box calling incorrect code paths.
  • Corrected RGB/BGR channel handling affecting:
    • Kalles Fraktaler (KFR) files
    • MAP palette files
    • COL true colour palette files
    • Fractint PAR inline palettes
  • Fixed animated GIF writing.
  • Fixed animated MPEG writing.
  • Improved animation frame handling and DIB packing behaviour.

ManpWIN 4.02f

This update improves the robustness of ManpWIN's perturbation engine and numerical stability across multiple precision modes, while introducing template-based infrastructure for future extensions.

  • Perturbation fix: corrected an issue caused by an uninitialised power value when reference generation was moved outside the CPerturbation class.
  • Rendering reliability: prevents incorrect fractal output that could appear after toggling under certain conditions.
  • Template framework: introduced template-based infrastructure, providing a foundation for extending fractal types and future perturbation support.
  • Arithmetic stability: stabilised trigonometric functions across multiple arithmetic types.
  • DD/QD improvements: corrected error handling in double-double and quad-double precision modes.
  • General stability: improved consistency for high-precision rendering, especially for cubic and higher-order fractals.
